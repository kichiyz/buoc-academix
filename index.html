MANUAL AUTHORING

Create from JSON

Paste JSON, import a .json file, or start with the guided template.

Waiting for JSON input. Nothing is published until you select Publish assessment.

New to JSON? Open the step-by-step guide
  1. Download the template and open it in Notepad or a code editor.
  2. Change the assessment title.
  3. Write each question prompt and its options. Multiple choice needs four unique options.
  4. Set correct_answer to exactly match one option. True/false options must be True and False.
  5. Set points to a whole number from 1 to 100 and add an explanation.
  6. Save as UTF-8 with a .json extension, then import it or paste the code above.
  7. Select Validate & preview, fix errors, inspect the student preview, then publish.

JSON uses double quotes, commas between items, and square brackets for lists. Do not add a comma after the last item.

{
  "schema_version": 1,
  "title": "Sample Mathematics Quiz",
  "exam_mode": "freeroam",
  "questions": [{
    "question_type": "multiple_choice",
    "prompt": "Evaluate \\(2^3 + 4\\).",
    "options": ["8", "10", "12", "16"],
    "correct_answer": "12",
    "explanation": "2 cubed is 8; 8 + 4 = 12.",
    "points": 2
  }]
}
